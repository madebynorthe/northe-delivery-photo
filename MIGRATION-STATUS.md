# Status de migração — NORTHE Delivery

Este repositório continua ativo temporariamente para a entrega fotográfica do Colares & Estácio.

## Regra

Não expandir este projeto para se tornar uma segunda plataforma geral de galerias/entregas.

Os recursos aprovados e reutilizáveis — especialmente integração com Drive, publicação, download e comportamento de galeria — devem ser avaliados para incorporação na base principal `audaz-delivery`, em migração gradual para NORTHE.

## Antes de tornar este repositório legado

- preservar a entrega atual do cliente;
- identificar workflow e componentes reutilizáveis;
- migrar o que fizer sentido para a base principal;
- testar a experiência substituta;
- só então arquivar este repositório.
