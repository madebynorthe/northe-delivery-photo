# NORTHE Delivery / Photo

Produto oficial da NORTHE para entregas fotográficas.

Esta base nasceu na galeria corporativa de Colares & Estácio, mas agora deve ser tratada como um produto reutilizável para qualquer entrega de fotografia.

## Função

Usar quando a experiência principal for:

- visualizar uma galeria;
- navegar por fotografias;
- selecionar imagens;
- abrir fotos em lightbox;
- baixar imagens individuais;
- baixar uma seleção ou a galeria completa.

## Regra

Não criar um novo repositório para cada cliente de fotografia. Cada nova entrega deve partir desta base e receber apenas os dados, imagens e identidade necessários para o cliente.

## Nome do produto

**NORTHE Delivery / Photo**

Nome técnico desejado do repositório:

`northe-delivery-photo`

## Estrutura atual

- `index.html` — interface da entrega
- `styles.css` — responsividade e UI
- `app.js` — galeria, lightbox, seleção e downloads
- `robots.txt` — controle de indexação
- `.github/workflows/publish.yml` — publicação e pacote de originais

## Infraestrutura

A implementação atual usa GitHub Pages e Google Drive para as imagens/originais. Essa infraestrutura pode evoluir sem mudar a função do produto.
